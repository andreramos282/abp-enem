# Notebooks

EDA e experimentos. Use nomes com número e tema, por exemplo:

- `01_amostragem.ipynb`
- `02_eda.ipynb`
- `03_baseline_regressao_logistica.ipynb`

Regras:
- Leia os dados de `data/` e os nomes de colunas de `ml/colunas_2023.py`.
- Use `random_state=42` em tudo que for aleatório.
- Limpe as saídas grandes antes de fazer commit.
- Código que for reutilizado (limpeza, pipeline) deve ir para `ml/`, não ficar só no notebook.
